# Changelog

## 1.0.0

- Initial release: ALTCHA proof-of-work CAPTCHA provider plugin for the Spryker Captcha module, with configurable Argon2id or PBKDF2 challenges, the HMAC secret managed in the Back Office configuration and generated by the `captcha-altcha:hmac-secret:generate` console command when none is stored (the Storefront creates and verifies challenges through the Zed gateway), a replay key for the single-use check of the Captcha module, and the Storefront, Back Office and Merchant Portal widget assets.
